## 🌟 Overview

**DOZE OPO** is a high-conversion mobile-first independent e-commerce prototype engineered for modern streetwear brands, TikTok creators, and cross-border B2B/B2C buyers. It blends contemporary urban aesthetics (brutalism, bold typography, glassmorphism) with high-efficiency procurement features.

---

## ✨ Key Features

### 1. 📱 Dynamic Mobile Experience
- **Interactive iOS-Style Frame & Fullscreen Modes**: Desktop developer preview toolbar with seamless toggle between 430px iPhone viewport and edge-to-edge full width.
- **Dynamic Multi-Currency Engine**: Live conversion across **USD ($)**, **EUR (€)**, **GBP (£)**, and **CNY (¥)** with unified rate updating across catalog, calculators, and shopping cart.

### 2. 🧮 Flexible Custom OEM Calculator
- **Instant Garment & Craft Matrix**:
  - Garment Type multipliers: `Tee` (1.0x), `Crewneck Sweatshirt` (1.5x), `Hoodies` (2.0x), `Zip Jackets` (3.0x), `Pants` (2.0x), `Jeans` (3.0x).
  - Print/Embroidery Crafts: `Heat Transfer` ($20 base), `Screen Print` ($40 base), `3D Puff Print` ($40 base), `DTG Direct Injection` ($50 base), `3D High-Density Embroidery` ($50 base).
  - Dynamic interactive formula: `Final Price = (Craft Base Price × Garment Multiplier) × Quantity`.
  - Preset quantity quick-select tags (`1`, `20`, `50`, `100`, `300`).

### 3. 👕 Product Catalog & T012 Heavy Tee PDP
- **Categorized Sidebar Navigation**: `All Items`, `Heavy Tees`, `Crewneck Sweatshirt`, `Heavy Hoodies`, `Zip Jackets`, `Pants & Jeans`.
- **T012 240G Raglan Sleeve Boxy Tee Product Detail Page**:
  - High-res 4-image swiper gallery with index counter.
  - 8 core SKU contrast colorways with garment photo swatches and real-time hero sync.
  - S to 2XL size selector chips with fit hints.
  - 48h 1-PC sample proofing, custom woven tags, and all-craft print tags.
  - Designer Setup notes (32S/2 double yarn combed cotton, 3.0cm bound collar, boxy drop shoulder cut).
  - Real model try-on cards (`Denis`, `Karen`, `ZEE`) with exact body measurements and sizing recommendations.
  - Full finish-garment dimension tables and on-model editorial lookbook gallery.
  - Sticky bottom action bar with direct WhatsApp messaging, Tech Pack RFQ intake, and 1-PC sample ordering.

### 4. 🛒 Sample RFQ Cart & Rapid B2B Intake
- Modal-based Tech Pack & artwork upload flow.
- Direct 1-tap WhatsApp consultation bridge.
- Full sample cart management with real-time totals.

## 🛠️ Tech Stack

- **Frontend**: Pure Semantic HTML5, Vanilla CSS3 (Custom Design Tokens, Flexbox, CSS Grid), Vanilla ECMAScript 6+

- **Assets**: Optimized WebP / PNG / JPG compressed assets
- **Dev Server**: Lightweight PowerShell HTTP Server (`server.ps1`)

## 🚀 Getting Started

To run the store locally:

```powershell
# In PowerShell:
powershell -ExecutionPolicy Bypass -File server.ps1
```

Then visit [http://localhost:8088/](http://localhost:8088/) in your browser.
